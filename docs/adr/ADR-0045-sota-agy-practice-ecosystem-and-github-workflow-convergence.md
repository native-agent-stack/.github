## Context and Problem Statement

Following [`ADR-0044`](ADR-0044-tier0-quant-native-thin-layer-m1-strict-hooks-p0-p5-and-full-landscape-convergence.md), the organization preserved its strict `schemaVersion: "4.0.0"` two-repository Next-Era boundary in `repositories.nextEraActiveTier` (`native-agent-stack/.github` and `seathatflowsinourveins/tier0-quant`) while evolving the live public GitHub topology: publishing **`seathatflowsinourveins/agy-sota-convergence`** (`v3.2.0`, Public) as the definitive Google Antigravity (`AGY 2.0`) practice, full-landscape meta-harness convergence guide, and distributable zero-wrapper native AGY Plugin Pack (`plugins/agy-sota-practice/`), transitioning live quantitative engineering on GitHub to **`seathatflowsinourveins/noesis`** (Public), and archiving **`seathatflowsinourveins/tier0-quant`** and **`seathatflowsinourveins/sota-research-convergence`** privately on GitHub (retained locally for continuity). Without formal org-level registration and a shared reusable GitHub SOTA workflow gate:

1. **Cross-Repo Customization, Plugin-Schema & Supply-Chain Drift:** Individual repositories risked drifting on `AGENTS.md` anti-bloat ratchets (`<=45L / <=1,600c`, `0` HTML comments), snake_case `.agents/rules/*.md` frontmatter (`<=24,000 B`), `.agents/skills/*/SKILL.md` description caps (`<=1,024c`), native AGY plugin-pack invariants (`v1/plugin.json`, opt-in root `hooks.json`, zero shadow `hooks/hooks.json`/`commands/`/`rules/AGENTS.md`), unexpanded `~/` deny rules, retiring `2026-11-30` model slugs, wildcard `0.0.0.0` MCP bridge binds (`CVE-2026-59726` *RufRoot*), and pinned scanner/action versions (`step-security/harden-runner v2.21.1` -> `v2.23.0`, `zizmor v1.33.1`, `xerj v1.0.0-rc.105`, `orca v1.4.278`).
2. **Meta-Harness Wrapper Bloat & Security Surface:** Third-party wrapper daemons duplicating native AGY 2.0 primitives (`/swarm`, `/goal`, `/teamwork`, `/boost`, `/run-workflow`, `/plan`, `/statusline`) inflate context cost (`>20%` per ETH Zurich `arXiv:2602.11988`) and expose unauthenticated localhost/wildcard bridges (`CVE-2026-59726`, CVSS `10.0`).
3. **Orca Worktree UX Skew & Missing Reusable AGY Practice Gate:** `dot-github`'s `orca.yaml` retained legacy `defaultTabs:` that `tier0-quant` (`PR #44`) and `agy-sota-convergence` had already removed, and `.github` lacked a dedicated `workflow_call` gate enforcing AGY customization hygiene, native plugin-pack contracts, sunset model bans, 40-char SHA-pinned workflows, `step-security/harden-runner v2.23.0`, and SHA-256-verified `gitleaks v8.30.1` + `zizmor v1.33.1`.

## Alternatives Considered

- **Mutating `repositories.nextEraActiveTier` keys directly:** Rejected — breaks the intentional `ADR-0040` / `ADR-0044` two-repo organization schema invariant (`{".github", "tier0-quant"}`) enforced by `tests/test_org_manifest.py::test_next_era_manifest_invariants_and_two_repo_boundary`. Modeling the broader live public vs. archived-private ecosystem under `workspacePracticeEcosystem` preserves backward compatibility while providing exact live GitHub provenance.
- **Adopting third-party meta-harness wrapper daemons (`oh-my-*`, `ruflo`, `bmad-method`, `hcom`) instead of a thin native AGY Plugin Pack:** Rejected — duplicates native AGY 2.0 primitives, violates `AGENTS.md` context-budget empirical findings (`arXiv:2602.11988`), and introduces critical bridge/supply-chain risks (`CVE-2026-59726`, CVSS `10.0`).
- **Interpolating `${{ inputs.* }}` directly in shell `run:` steps or using mutable GitHub Action version tags (`@v4`, `@latest`):** Rejected — fails `zizmor` `template-injection` and `unpinned-uses` audits and violates `ADR-0006` and `scripts/merge_gate.py`.
