## Context and Problem Statement

Following [`ADR-0044`](ADR-0044-tier0-quant-native-thin-layer-m1-strict-hooks-p0-p5-and-full-landscape-convergence.md), the organization preserved its strict `schemaVersion: "4.0.0"` two-repository Next-Era boundary in `repositories.nextEraActiveTier` (`native-agent-stack/.github` and `seathatflowsinourveins/tier0-quant`) while evolving the live public GitHub topology: publishing **`seathatflowsinourveins/agy-sota-convergence`** (`v3.1.0`, Public) as the definitive Google Antigravity (`AGY 2.0`) practice & convergence reference, transitioning live quantitative engineering on GitHub to **`seathatflowsinourveins/noesis`** (Public), and archiving **`seathatflowsinourveins/tier0-quant`** and **`seathatflowsinourveins/sota-research-convergence`** privately on GitHub (retained locally for continuity). Without formal org-level registration and a shared reusable GitHub SOTA workflow gate:

1. **Cross-Repo Customization & Supply-Chain Drift:** Individual repositories risked drifting on `AGENTS.md` anti-bloat ratchets (`<=45L / <=1,600c`, `0` HTML comments), snake_case `.agents/rules/*.md` frontmatter (`<=24,000 B`), `.agents/skills/*/SKILL.md` description caps (`<=1,024c`), unexpanded `~/` deny rules, retiring `2026-11-30` model slugs, and pinned scanner versions (`zizmor v1.32.0` vs. `v1.33.1`, `xerj v1.0.0-rc.104` vs. `v1.0.0-rc.105`, `orca v1.4.268` vs. `v1.4.278`).
2. **Orca Worktree UX Skew:** `dot-github`'s `orca.yaml` retained legacy `defaultTabs:` that `tier0-quant` (`PR #44`) and `agy-sota-convergence` had already removed in favor of plain shell-first worktree control.
3. **Missing Reusable AGY Practice Gate:** `.github` exposed `reusable-sota-gate.yml` and `reusable-sota-lane-maintenance.yml`, but lacked a dedicated `workflow_call` gate enforcing AGY customization hygiene, sunset model bans, 40-char SHA-pinned workflows, `step-security/harden-runner`, and SHA-256-verified `gitleaks v8.30.1` + `zizmor v1.33.1`.

## Alternatives Considered

- **Mutating `repositories.nextEraActiveTier` keys directly:** Rejected — breaks the intentional `ADR-0040` / `ADR-0044` two-repo organization schema invariant (`{".github", "tier0-quant"}`) enforced by `tests/test_org_manifest.py::test_next_era_manifest_invariants_and_two_repo_boundary`. Modeling the broader live public vs. archived-private ecosystem under `workspacePracticeEcosystem` preserves backward compatibility while providing exact live GitHub provenance.
- **Interpolating `${{ inputs.* }}` directly in shell `run:` steps or using mutable GitHub Action version tags (`@v4`, `@latest`):** Rejected — fails `zizmor` `template-injection` and `unpinned-uses` audits and violates `ADR-0006` and `scripts/merge_gate.py`.
